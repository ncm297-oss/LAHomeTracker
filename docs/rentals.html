How this works

  1. A daily job pulls every for-rent home in the tracked zips from Realtor.com, which carries MLS lease listings plus feeds from Zillow, Zumper and others. Homes that stop showing up for 3 days are marked gone.
  2. Saved-search alert emails from Zillow, Apartments.com (which also feeds Westside Rentals), Redfin, HotPads, Trulia and Zumper are read from Gmail, once Gmail is connected. That's how homes listed only on those sites get in.
  3. Every home has a Zillow and a web search link, so you can see where else it's posted in one click.
  4. Saw a sign or a Craigslist post? python -m tracker rentals-add --address "…" --zip 90066 --rent 6500 --beds 3 --source sign
  5. Triage: python -m tracker rental-note "Wade St" --status shortlist --text "call Tue" (statuses: shortlist, contacted, toured, applied, pass). Notes live in data/rental_notes.yaml and can be edited on GitHub too.
